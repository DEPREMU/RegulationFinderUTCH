# Generated artifacts

Most artifacts are ignored. `.gitignore` allows `artifacts/training/` to be added for reproducible Week 2 and Week 3 training and development calibration. Week 2 files use the original names (`real-model.json`, `real-training-manifest.json`, and related reports). Week 3 files use the `week3-` prefix and include the expanded model, manifest, development threshold grid, selected settings and evaluation report. The separate final evaluation set and its results are not included. School permission and external redistribution terms remain pending.

From root: `uv run --frozen regulation-finder train` writes the synthetic demo model. Each search/web/evaluation command loads its selected model. A versioned JSON artifact contains training vocabulary, sorted topic labels, learned log priors/likelihoods and a SHA-256 fingerprint of metadata, articles and training rows. It is not a pickle and executes no code. Changes to those training inputs require retraining; development and final evaluation rows do not enter fit.

Reproduce synthetic demo outputs with `uv sync --frozen`, validate, train, then evaluate. Save settings, code commit, uv.lock, dataset fingerprint and model hash alongside results. Training is deterministic for identical files, NumPy/tool versions and settings. The Week 3 independent evaluation freeze is `week3-independent-evaluation-freeze.json`; the one-time report will be `week3-independent-evaluation.json`. The earlier Week 3 question diagnostic is retained only as a pre-training record; those questions are now part of the Week 3 training set.
